# 02: Invite another adult

**What to build:** An invited adult joins the existing household with equal management permissions.

**Blocked by:** 01: Create a household and access child profiles.

**Status:** ready-for-agent

- [ ] An adult can issue an invitation and the recipient can accept using adult authentication.
- [ ] The invited adult joins the intended household with equal management permissions.
- [ ] Invalid, expired or reused invitations fail clearly without duplicate memberships.
- [ ] Children cannot issue or accept adult invitations using child access.
- [ ] Deliver persistence, server validation and permissions, mobile UI, and meaningful regression coverage for this behaviour.
- [ ] Confirm success only after saving; failed actions show useful errors and allow safe retries.
