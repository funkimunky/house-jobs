# 08: Edit, pause and archive recurring chores

**What to build:** Adults manage recurring definitions while preserving existing work and history.

**Blocked by:** 03: Publish weekday chores to the child board.

**Status:** ready-for-agent

- [ ] Adults can edit instructions, rewards and schedules; changed terms apply to future occurrences only.
- [ ] Existing occurrence terms remain intact through edits, pauses and archival.
- [ ] Pausing or archiving stops future occurrence generation, including scheduler retries.
- [ ] Existing claims, submissions and completion or financial history remain accessible and follow the lifecycle.
- [ ] Define and verify expiry boundaries for existing work when schedules change or future generation stops; stopping a chore does not silently discard existing work.
- [ ] Deliver persistence, server validation and permissions, mobile UI, and meaningful regression coverage for this behaviour.
- [ ] Confirm success only after saving; failed actions show useful errors and allow safe retries.
