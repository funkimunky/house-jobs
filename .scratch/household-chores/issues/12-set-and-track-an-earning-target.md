# 12: Set and track an earning target

**What to build:** Children manage one target and see progress based on approved earnings.

**Blocked by:** 05: Submit, approve and earn a reward.

**Status:** ready-for-agent

- [ ] A child sets one active target with a name and amount; adults can help edit it.
- [ ] Progress is labelled “earned towards target” and counts approvals since the target began.
- [ ] Editing preserves progress; replacing starts a new goal at zero and counts only approvals after its start.
- [ ] Qualifying earnings remain counted when subsequently paid; reaching the target permits further earnings.
- [ ] Children can access only their own target; the view measures earning progress rather than actual savings or spending.
- [ ] Deliver persistence, server validation and permissions, mobile UI, and meaningful regression coverage for this behaviour.
- [ ] Confirm success only after saving; failed actions show useful errors and allow safe retries.
